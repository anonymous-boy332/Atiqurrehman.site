# Atiq Ur Rehman — Premium 3D Portfolio

Files:
- index.html
- style.css
- script.js

Important:
- All portfolio visuals are created directly in HTML/CSS/SVG.
- No temporary stock photos or image URLs are required.
- The floor plan, interior room, SaaS dashboard, e-commerce mockups, phones, posters and devices are embedded/generated in the code.
- Google Fonts are loaded remotely in CSS; replace with local fonts if you need a fully offline build.
- Contact form is front-end only and must be connected to an email/backend endpoint before production use.

Open `index.html` in a browser.
